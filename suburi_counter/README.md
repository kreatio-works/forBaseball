# 素振りカウンター ⚾

声で数えるだけでカウントできる、野球の素振り記録アプリです。
手がバットでふさがっていても、「いち、に、さん…」と数えながら振れば自動でカウント。
がんばった記録はスプレッドシートに残せるので、「ほんとに振ったの？」がなくなります。

**アプリはこちら → https://fireworks2021tm-bit.github.io/suburi-counter/**

インストール不要。スマホのブラウザ（iPhoneはSafariかChrome推奨）で開くだけで使えます。

## できること

- 🎤 **声でカウント**：「いち、に、さん…」と数えながら振ると自動でカウントアップ
- 🎯 **目標は自分で決める**：朝に50回、夜に50回など、小分けもOK。合計が目標に届くと画面がお祝いしてくれます
- 📋 **ズルしにくい記録**：早口で数えても無効（1回1.2秒以上）。記録には開始・終了時刻と所要時間が残ります
- 📊 **コーチへ自動報告**（チーム運用時）：セッション終了時にGoogleスプレッドシートへ自動送信。電波がない場所で練習しても、次に電波が入ったときに再送されます
- 🗣 **言いまちがい対応**：「まちがい」と言うと1つ戻ります（−1ボタンもあり）

## 使い方（選手・保護者向け）

1. アプリを開く（ホーム画面に追加しておくと便利）
2. 「きょうの目標」に回数を入れる
3. **スタート** → マイクを許可 → 数えながら振る！
4. 終わったら **セッション終了して記録する**

詳しくは [使い方ページ](https://fireworks2021tm-bit.github.io/suburi-counter/help.html) へ。

## チームで使う（コーチ・管理者向け）

コーチが記録用スプレッドシートを1つ用意すれば、チーム全員の記録が1か所に集まります。
各家庭の作業は「配られたリンクを開いて、ニックネームを入れる」だけです。

### 1. スプレッドシートとGASを用意する

1. Googleスプレッドシートを新規作成（名前は「素振り記録」など）
2. 拡張機能 → Apps Script を開き、以下を貼り付けて保存

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];

  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['受信日時', '名前', '日付', '開始', '終了', '所要秒',
                     '音声カウント', '手動カウント', '合計', 'その日の目標']);
  }

  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),   // サーバー側の受信日時（改ざん防止の基準）
    d.name || '', d.date, d.start, d.end, d.seconds,
    d.voice, d.manual, d.total, d.goal
  ]);

  return ContentService.createTextOutput('ok');
}

function doGet() {
  return ContentService.createTextOutput('素振り記録：受付OK');
}
```

3. デプロイ → 新しいデプロイ → 種類「**ウェブアプリ**」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示されたURL（`…/exec` で終わるもの）をコピー
5. ブラウザでそのURLを開いて「素振り記録：受付OK」と出れば準備完了

※ コードを修正したときは「デプロイを管理 → 鉛筆マーク → 新バージョン → デプロイ」で更新します（「新しいデプロイ」だとURLが変わるので注意）。

### 2. チームに配る

アプリURLの後ろに `?gas=` を付けてGASのURLをつなげたリンクを、LINEなどで配ってください。

```
https://fireworks2021tm-bit.github.io/suburi-counter/?gas=https://script.google.com/macros/s/○○○/exec
```

このリンクを開くだけで送信先が自動設定されます。あとは各自がアプリの「設定」でニックネームを入れれば完了です。

### 3. 集計のヒント

シートのK2に以下を入れて下へコピーすると、「その選手のその日の合計」が出ます（Excel互換の関数のみ使用）。

```
=SUMIFS(I:I, B:B, B2, C:C, C2)
```

## ズル防止の考え方

- 1カウントの最短間隔は1.2秒。早口で「1,2,3…」と連呼しても無効です
- 「受信日時」はGoogleサーバー側で記録されるため、端末の時計を変えても本当の時刻が残ります
- 所要秒と回数を見れば「100回を90秒」のような不自然な記録はすぐ分かります
- ニックネームは自己申告のため、厳密な本人認証はありません。チーム内の信頼ベースでの運用を想定しています

## 技術メモ

- 1ファイルのHTML（ビルド不要）。GitHub Pagesでそのまま動きます
- 音声認識はWeb Speech API（`ja-JP`）。iOSでは認識が自動で切れるため、セッション中は自動再起動します
- 記録の送信先URLはコードに埋め込まず、各端末の設定（localStorage）に保存されるため、このリポジトリをフォークしてもあなたのシートのURLが公開されることはありません
- 画面スリープ防止にWake Lock APIを使用
