# 自主練カウンター

毎日の自主練メニューを数えて記録する、スマホ用のブラウザアプリです。
素振りカウンターと同じ仕組み（HTML1枚・音声認識・端末内記録・GAS送信）で作っています。

## メニュー（初期値）

| 種目 | 目標 | 数え方 | 最短間隔 |
|---|---|---|---|
| 腹筋 | 30回 | 声 | 1.2秒 |
| 背筋 | 30回 | 声 | 1.2秒 |
| 腕立て | 30回 | 声 | 1.2秒 |
| ダッシュ | 10本 | タップ | 10秒 |
| 坂道ダッシュ | 10本 | タップ | 10秒 |
| 素振り | 200回 | 声 | 1.2秒 |

## メニューの編集

「設定」で種目をタップすると、次の内容を変えられます。

- 名前（例：「ダッシュ（往復）」）、1日の目標、単位（回・本・セットなど）
- 数え方（声で数える／タップ）、カウントの最短間隔
- やる曜日
- 種目の追加（＋ 種目を追加）と削除

削除してもこれまでの記録（履歴・送信済みの行）は消えません。
`index.html` の `DEFAULT_MENU` は、はじめて開いたときの初期メニューです。

## 使い方

1. ホームで種目をえらぶ
2. **声の種目**：スタート → マイクを許可 →「いち、に、さん…」と数えながらやる
   **タップの種目**：スタート → 1本走るたびに「1本 おわった！」を押す
3. 「終了して記録する」でその日の合計に加算（何回かに分けてもOK）

## やる曜日

- 「設定」で種目ごとに、やる曜日を選べます（初期値は毎日）
- お休みの曜日の種目は、ホームの下にうすく表示され、「おわった種目」の数に入りません
- お休みの日でも、えらべば記録はできます

## 0回に戻す

- おためしで数えたあとなどは、種目の画面の「きょうの記録を0回に戻す」で、その種目のきょうの合計を0にできます
- 履歴は消さず、マイナスの「リセット」行を足します（スプレッドシートにも送られ、合計が0に合います）

## きょうのひとこと

- ホームの下の「きょうのひとこと」に、その日のメモを1行（60文字まで）残せます
  例：「バッティングセンターへ行って100本」
- 書けるのは当日分だけです。書き直すと上書きされます

## 1週間の記録

- ホーム右上の「この1週間」を押すと、月曜はじまりの1週間を一覧で見られます
- 日ごとに、種目別の回数／目標、達成した種目数、ひとことが並びます
- 「前の週」「次の週」でさかのぼれます（端末内に残っている記録の範囲）

## ズル防止のルール

- 声は +1 ずつしか進まない（いきなり「100」と言っても飛ばない）
- 最短間隔より速い声・タップ・+1ボタンは無効
- 認識抜けの追いつきは3つ先まで、かつ経過時間が妥当なときだけ
- 記録には開始・終了時刻、所要秒、音声カウントと手動カウントの内訳が残る

## 記録の保存先

- 端末内（localStorage、キーは `jr_` で始まる）。素振りカウンター（`sb_`）とは別管理
- 設定にGASのURLを入れると、終了のたびにスプレッドシートへ送信（電波がないときは次回に再送）

## スプレッドシートに集める（任意）

GASのコードは、このフォルダの `Code.gs` です。スプレッドシートの Apps Script に全文を貼り付け、
ウェブアプリとしてデプロイします（実行：自分／アクセス：全員）。手順は素振りカウンターと同じです。

- 記録は、いちばん左のシートに1行ずつ追加されます
  列：受信日時 / 名前 / 日付 / 種目 / 入力方式 / 開始 / 終了 / 所要秒 / 音声カウント / 手動カウント / 合計 / 1日の目標 / ひとこと
- 「きょうのひとこと」は、種目が「ひとこと」・入力方式が「メモ」の行として届きます
- 「0回に戻す」を使うと、入力方式が「リセット」・合計がマイナスの行が届きます
- 素振りカウンター用のスプレッドシートとは列が違うので、別のシート（別のGAS）にしてください

### 週間集計シート

記録が届くたびに「週間集計」シートを自動で作り直します（コーチ・保護者が見る用）。

- 1行 ＝ 選手1人の1日。列 ＝ 週（月曜の日付）/ 名前 / 日付 / 曜日 / 種目ごとの回数 / ひとこと
- 目標に届いた種目のセルは、うすい緑になります
- 新しい週が上。見出しのフィルタで、名前や週をしぼりこめます
- このシートは毎回作り直すので、手で書きこんだ内容は消えます
- 種目の名前を変えると、変える前と後で別の列になります
- 手動で作り直すときは、メニューの「自主練 → 週間集計を更新」（シートを開き直すと出ます）

### すでにデプロイ済みのGASを更新するとき

1. Apps Script を開き、コードを `Code.gs` の全文に置きかえて保存
2. デプロイ → **デプロイを管理** → 鉛筆マーク → バージョン「新バージョン」→ デプロイ
   （「新しいデプロイ」だとURLが変わるので注意）
3. スプレッドシートを開き直し、「自主練 → 週間集計を更新」を1回実行（初回は承認が出ます）

配布リンクは `…/jishuren_counter/?gas=（GASのURL）&name=（ニックネーム）` の形で、開くだけで設定されます。
