# RidePlan — チームの配車表メーカー

クラブ・チームの係の人が、**一人で**メンバーを車に割り当てて配車表を作るためのアプリです。
HTMLファイル1枚で動き、ログイン・登録は不要。データは使っている端末のブラウザ内だけに保存されます。

- 公開ページ：https://kreatio-works.github.io/forBaseball/rideplan/
- 制作：[KREATIO WORKS](https://kreatio-works.github.io/)

## できること

- 車（家庭ごと）とメンバーを設定に登録
- 試合ごとに、出す車を選び、運転者・荷物席・メンバー外席（家族など）を差し引いた席にメンバーを割り当て
- 座席マップをタップして乗せる／外す、欠席の管理
- 乗る人・席・未割当の集計を常時表示
- 試合名・日付・便（行き／帰り／往復）・集合時間・集合場所・出発時間・行き先・メモ
- 車ごとの備考（試合ごと）
- 経費の精算：車ごとに高速代・駐車場代・ガソリン代（実費／定額／距離×単価／なし を設定で選択）を入力し、1試合分または月まとめのExcelを出力（「明細」＋「運転者別集計」の2シート、集計は数式）
- 出力：LINE用テキスト（コピー）、A4縦の配車表（印刷・PDF保存）
- 配車の複製、過去の配車からコピー
- データのバックアップ書き出し・読み込み（JSON）

## 使い方

1. **⚙️設定**：クラブ名、車（車名・定員・普段の運転者）、メンバーを登録
2. **🚗配車**：「＋新しい配車」で試合情報を入力 → 出す車をオン → 空席の「＋」または未割当の名前をタップして乗せる
3. **出力**：「LINE用テキスト」をコピー、または「印刷・PDF」

アプリ内の「❓使い方」にも同じ説明があります。

### ホーム画面に追加

- iPhone：Safariで開き、共有ボタン →「ホーム画面に追加」
- Android：Chromeで開き、「⋮」→「ホーム画面に追加」

## 注意

- データは端末のブラウザ内（localStorage）だけに保存されます。機種変更・別端末で使う前に「設定 → バックアップ → 書き出す」でファイルを保存し、新しい端末で読み込んでください。
- ブラウザの履歴・サイトデータを消すとデータも消えます。
- 公開URLは誰でも開けますが、他の人の入力内容が見えることはありません。

## 技術

- 単一HTMLファイル（HTML / CSS / JavaScript）。経費Excelの書き出し時のみ ExcelJS を CDN から読み込みます（それ以外はオフラインでも動作）
- GitHub Pagesでそのまま公開できます
